# Life Meexmo

Aplicativo mobile para acompanhamento de performance pessoal com foco em:
- corrida
- academia
- alimentação e calorias
- conquistas e evolução

## Como rodar

1. Instale o Flutter SDK.
2. No terminal, rode:

```bash
flutter pub get
flutter run
```

## Features incluídas

- login inicial
- tema vermelho e preto
- quatro abas principais:
  - corrida
  - academia
  - alimentação e calorias
  - conquistas
- câmera para analisar refeição e estimar calorias
- estrutura pronta para expansão com Firebase, banco e autenticação real

## Observação

Esta versão é um app Flutter real, não uma página HTML estática. O GitHub Pages só é uma preview visual e não executa a lógica do app mobile.
